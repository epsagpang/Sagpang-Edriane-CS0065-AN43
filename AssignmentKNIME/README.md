Asynchronous Activity 1: Student Early Warning Tool Using KNIME

This project uses KNIME to predict student risk status from academic performance data.

## Files
- KNIME_assignment.knwf - the exported KNIME workflow
- student_performance_knime - the dataset used by the workflow

## Algorithms
- Decision Tree
- Logistic Regression
- Random Forest

## How to Run
1. Open KNIME Analytics Platform.
2. Import the .knwf file.
3. Set the CSV Reader to use the included dataset.
4. Run all the nodes.
5. Check the Scorer node results.
